A little about me

I'm Rodgers Onyango, the developer behind RoyTech.

I spend my time building software, experimenting with ideas, fixing things that break, and learning through real projects. Most of my work revolves around WhatsApp automation, APIs, media utilities, and tools that make everyday tasks easier.

I prefer working code over big promises. There is always something to improve, something new to learn, and another idea worth building.
