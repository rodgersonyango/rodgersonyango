<h2 align="center">What I Do</h2>

<p align="center">
  <img src="https://user-images.githubusercontent.com/74038190/229223263-cf2e4b07-2615-4f87-9c38-e37600f8381a.gif" width="400" alt="Coding animation" />
</p>

I build **bots and automation systems**  the kind that handle real work, real users, and real conversations without falling apart.

My focus is on making software that **responds, reacts, and runs on its own**, so people don't have to. From WhatsApp MD bots to Messenger chat bots and customer service automation, I design systems that scale conversations and cut out repetitive manual work.

I'd rather ship something that runs than talk about something that might.

---

<h2 align="center">Core Focus Areas</h2>

<table align="center">
  <tr>
    <td width="50%" valign="top">
      <h3>WhatsApp MD Bots</h3>
      Multi-device WhatsApp automation command handlers, plugin systems, media processing, group management, and messaging utilities built to run 24/7.
    </td>
    <td width="50%" valign="top">
      <h3>Chat Bots</h3>
      Conversational bots with command routing, context handling, and API-driven responses. Built to feel natural, not robotic.
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Facebook Messenger Bots</h3>
      Messenger automation for pages and businesses auto-replies, menu flows, lead capture, and webhook-based event handling.
    </td>
    <td width="50%" valign="top">
      <h3>Customer Service Bots</h3>
      Automation that answers FAQs, routes requests, and handles first-line support so humans only step in when it matters.
    </td>
  </tr>
</table>
